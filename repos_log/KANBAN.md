# Shared Kanban — pytorch_playground

> Board for all agents working on this repo. Read [goal.md](./goal.md) first.
>
> **How to use**
> - **Exactly four chapters: `TODO`, `IN PROGRESS`, `DONE`, `BACKLOG / IDEAS`.** Do not add
>   others — no `REVIEW / WAITING`, no per-handoff sub-tables. A card blocked on a human
>   decision stays in `TODO` with `Blocked:` named in its cell; a card added by a handoff
>   goes into the `TODO` table in ID order. Past handoffs' notes are kept as blockquotes
>   *inside* a chapter, never as a chapter of their own.
> - Move a card between chapters in the same commit that does the work.
> - Cards are stable IDs — reference them in commits, PRs, and handoffs (`P1-3`).
> - Add an `Owner` and `Handoff` when you pick a card up. Add new cards to `TODO` in ID
>   order with a `P1/P2/P3` prefix; don't renumber existing cards.
> - A card moves to `DONE` only when its acceptance criteria are met **and** the evidence — the
>   command, the host, and the raw output — is its own file in [`evidences/`](./evidences/INDEX.md),
>   linked from the card's **Evidence** column. **Never cite a handoff section as the evidence**
>   (~~`Evidence: HANDOFF_004 §6.4`~~): that forces the next agent to read an ~800-line document to
>   check one claim. One file per experiment in `evidences/`; handoffs keep the narrative and the
>   decisions.
> - **Do not park a card in `IN PROGRESS` with an
>   "update" appended once its work is finished** — either it meets acceptance (move it) or
>   it does not (say what is still missing, in a **Still missing:** clause).
>
> Legend — **P1** blocks any training run · **P2** correctness/reproducibility · **P3** polish
